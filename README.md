# TruWorlds Core Scripts
A public repository containing the source code for TruWorlds core scripts. These scripts come from the TruWorlds engine itself and provide important core functionality common to every world or game.

While you can't modify core scripts directly, we hope that open sourcing them serves as a useful reference if you'd like to create your own custom UI or functionality.

### Note on GitHub File Preview
TruScript is a new programming language developed by TruWorlds. It does not yet have syntax highlighting support on Linguist, so previewing files directly on GitHub will not render any syntax highlighting. 

We recommend using a text editor that supports TruScript syntax highlighting for the best viewing experience.
